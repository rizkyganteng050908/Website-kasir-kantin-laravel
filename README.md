# 🍽️ POS Kasir Kantin Digital (Laravel)

Aplikasi Point of Sale (POS) berbasis web untuk manajemen transaksi kasir kantin yang cepat, praktis, dan dilengkapi manajemen stok otomatis serta cetak struk termal.

## ✨ Fitur Utama
- **Transaksi Kasir Cepat:** Pilih menu dengan tampilan responsif, atur jumlah pesanan, dan hitung kembalian otomatis.
- **Manajemen Menu & Stok:** Tambah menu baru dan lakukan *restok* langsung dari antarmuka web. Stok otomatis berkurang setiap kali transaksi berhasil.
- **Cetak Struk Termal:** Tampilan struk siap cetak (standar kertas 80mm/58mm) setelah pembayaran selesai maupun cetak ulang dari riwayat transaksi.
- **Laporan Harian:** Pantau total omzet hari ini dan riwayat 10 transaksi terakhir secara *real-time*.
